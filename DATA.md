# Data

## Geometry

`static/geometry.json` is generated by the current `worldparser.py` from the
bundled Natural Earth source. It contains 175 country records and 7,491 shared
points in a Mollweide projection. Its coordinates differ from the original
2020 `_006` snapshot by at most 2e-15 in normalized coordinates. A test locks
the current generator to the committed file going forward.

The geometry version is derived from a hash of its countries and points. Any
geometry change therefore requires matching frames instead of silently passing
the player's compatibility check.

The earlier numbered geometry files used the same polygons and points. Their
last topology change added solver bridges connecting Senegal to Brazil, Italy
to Spain, and Iran to Qatar. The current solver geometry also anchors Iceland
to Great Britain, ties Lesotho's shared inner ring to South Africa's outer
ring.

## Population timeline

`data/population.json` is the historical and projected population input used by
the original Gapmover. Its original source and normalization procedure have not
yet been recovered.

Historical records do not cover every present-day country. The legacy solver
uses the average target multiplier of the country's continent when a value is
missing. This policy is retained only to reproduce the current output. New
population data needs an explicit mapping for historical predecessors before
it replaces the legacy data.

`data/country_mappings.json` resolves five obsolete or project-specific codes
to the canonical geometry. It also records the remaining continent-average
fallback as an explicit legacy policy. `python generate.py audit` writes every
case to `baseline/data_audit.json` so it cannot pass unnoticed.

`static/population_frames.json` contains generated 1800–2100 frames using the
canonical bridge and layout rules. Each year starts from the base map rather
than accumulating the preceding year's distortion. Five projection passes
restore each part to its scaled template while averaging shared border points.
`baseline/population_frames.json.gz` preserves the previously shipped frames
for comparison because their original generation harness is missing.

## World Sizer measurements

`data/measurements.json` is the assembled input for World Sizer. The old CIA
Factbook scraper did not reproduce its fields or country set and has therefore
been removed.

`python update_sources.py world-bank` downloads a normalized source snapshot
through 2025 to `data/sources/world_bank.json`. It looks back to 2019 and keeps
the latest available observation year for every country and field. The snapshot
covers population, surface and land area, CO2 emissions, armed forces, GDP,
people living with HIV, exports, alcohol consumption per person, labor force,
and forest area. The data comes from stable World Bank indicator IDs rather
than page scraping.

Oil production comes from EIA's public International Energy Data bulk download.
Run `python update_sources.py eia` to write `data/sources/eia.json`; no API key
is needed. Running the script with no source argument updates both snapshots.
The oil series is crude oil including lease condensate, measured in thousands
of barrels per day.

`python build_measurements.py` assembles the snapshots into
`data/measurements.json`. Alcohol consumption is estimated as the published
per-person value times population so the map represents total consumption.
Olympic medal totals are the 1896–2024 all-games snapshot from Craig
Nevill-Manning's Medals per Capita.

`data/measurement_manifest.json` lists the fields retained by the current player.
Productive land area is removed because the served dataset has no values for
it. The source snapshots cover every retained field.

Missing measurements are estimated from the country's population and its
continent's observed value per person. Countries that also lack population
retain the solver's continent-average fallback. Zero measurements remain real
zeros. The data audit continues to report source coverage rather than hiding
these cases.

The measurement paths run the ported solver for 299 ticks, matching the old
browser loop's initial history frame plus 299 generated frames. Five
checkpoints per path keep the compressed frame bundle below the 1.5 MB budget.
Indonesia's parts expand around the country's area-weighted center. Sumatra is
anchored to the southern tip of Malaysia as a proxy for Singapore, which is not
present in the coarse source geometry. The projection cleanup keeps this
cross-country anchor from folding either coastline. These layout changes are
used for newly generated frames but not for comparisons with the preserved
population frames.

Two Philippine islands that were automatically tethered to Malaysia are
instead anchored within the Philippine island chain. At the 2080 target this
reduces overlap among Philippine shapes from about 14% to below 1% without
expanding the chain's overall layout. China is bridged to the Philippines so
its much larger 1800 multiplier does not expand over the unconnected island
chain.

The port does not reproduce the opaque legacy population equilibria exactly,
so they remain the comparison baseline. The unusually large 2020
maximum displacement in the continuation run is on Pakistan; an independent
2020 run instead settles into a different equilibrium around Myanmar. The
median displacement remains small in both cases.

The audit reports missing, zero, and non-numeric values for every field offered
by the site.
